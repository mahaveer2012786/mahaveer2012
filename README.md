# Mahaveer Enterprises Website

Static, responsive product catalogue website created from the supplied `Mahaveer.pdf` catalogue.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Contents

- `index.html` - website structure
- `styles.css` - responsive visual system
- `script.js` - search, filters and product modal
- `app-data.js` - 143 catalogue products
- `assets/products/` - 143 product images cropped from the supplied catalogue
- `assets/catalogue-cover.webp` - catalogue cover visual
- `assets/Mahaveer-Product-Catalogue.pdf` - supplied catalogue PDF
